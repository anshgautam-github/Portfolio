# Journey: painted art

Put your illustrations in `public/journey/`. Each file is optional: a missing one falls back to the code-drawn version.
Use art you made or have the licence to use. Export at 2x for sharp screens, keep each JPG under about 600 KB and each PNG under about 900 KB.

| file | what | size (px) | notes |
|---|---|---|---|
| `sky.jpg` | tall sky, clouds at the BOTTOM, open sky at the top | 2560 x 2880 | the camera tilts from the bottom up to the top |
| `hill.png` | hill + tree in the foreground | 2560 x 1440 | transparent PNG, ground at the bottom edge |
| `leaf-big.png` | the large hero leaf | 900 x 1300 | transparent, TIP UP; the headline sits across it |
| `sea.jpg` | sky over a sea, horizon at about 68% height | 2560 x 1440 | |
| `pond.jpg` | top-down pond | 2560 x 2300 | the scene scrolls over it |
| `shore.jpg` | pond edge on the left, autumn ground on the right | 2560 x 1440 | the paper note sits over it |
| `koi.png` | one koi, seen from above | 800 x 300 | transparent, HEAD POINTING RIGHT |
| `flower.png` | one floating blossom | 256 x 256 | transparent |
| `leaf-1.png` ... `leaf-4.png` | small falling leaves | about 256 tall | transparent, TIP UP |

Everything else (camera moves, parallax, leaf fall, ripples, koi swimming, grain, the paper note) is already wired.
